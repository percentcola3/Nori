# 明确勾选后的整份应用数据卸载

2026-10-20。用户确认：允许清理应用独占的历史、快照、配置和扩展，默认不勾选；共享数据和真实项目保留。本约定补充此前的历史保护规则，不开放普通垃圾清理中的逐会话文件删除。

同日补充：软件卸载、普通 CLI 卸载、Agent 卸载均提供此能力；已卸载的关联数据在手动扫描中进入「卸载垃圾」，默认不勾选。沿用已有 leftovers 展示分组，不新增平行分类。

## 执行约定

- 软件卸载清单中的 `agentData` 是可选数据。未勾选的项目保留，勾选后只移入废纸篓。
- Agent 卸载后的关联数据入口和已卸载 Agent 的“查看残留”共用独立的数据审查浮层，每次打开均为空选择。
- 软件卸载清单直接列出可选数据；普通 CLI 与 Agent 程序卸载成功后打开相同的数据审查。包管理器仍负责程序本体，不绕过依赖检查。
- `UninstallDataOwner` 统一软件 Bundle ID/名称、CLI 包名/命令和 Agent 归属；`UninstallPlanningService.dataCandidates` 共用登记目录、共享引用和真实仓库检查。扫描与执行采用相同规则。
- `uninstall-owners.json` 仅保存已发现的软件/CLI 归属元数据，帮助识别清空废纸篓之后的残留，不保存选择、文件身份或删除授权。已卸载 Agent、废纸篓内的 App 和可确认归属的反向 DNS 数据不要求先有这份记录。仅凭未知的 `~/.name` 目录不会推断它已卸载。
- 扫描后的卸载垃圾始终为手动复核项；快速/定时清理不选择这些数据。执行绑定扫描时的身份、选择及归属；重装、目录替换、共享关系变化或无法检查占用时保留并报告。清理页也只移入废纸篓。
- `AgentCatalog.fullUninstallDataCandidates` 只认已登记的数据根，复核其他安装、CLI、Skill 链接、配置引用和 Git 项目。共享项、工作树和真实仓库从父目录中拆出保留。未知配置、超出仓库检查预算的目录保留。
- 配置引用仅从声明的 MCP JSON/JSONC 键及 TOML 段读取；Codex 的项目信任根、界面设置等不代表所有下级应用数据均为共享资源。仍保护实际 MCP 命令/目录参数、相对路径引用和配置链接目标。
- `NativeCore.UninstallDataPlan` 固定路径与文件身份。`UninstallDataAuthorization` 只能在原生卸载代码内创建，限定同一用户目录、已确认的独占路径和可恢复的废纸篓操作。
- 删除前和占用检查后的最终边界重新检查归属。新安装、新共享引用、文件身份变化、占用、权限或白名单阻止操作时保留数据，并报告未完成。
- 其他 CLI 的可执行文件及相邻程序目录保留。直接列出的 SQLite 主文件和 WAL/SHM/journal 联动选择并整组复核，不能只删除其中一部分。
- 软件卸载会在应用本体移除后处理数据。排队期间的数据目录身份变化使整次卸载计划失效，不用新目录替换原先确认的目录。
- 普通 `applyCleanup` 和 Agent 缓存清理不能使用该授权，原有历史保护仍有效。官方逐会话历史接口的启用状态不变。

## 验证

`script/test_uninstall_residue.sh` 覆盖真实隔离文件的移出、空选择、普通清理伪造选择、真实仓库、工作树、共享 Skill/MCP、含空格的配置目录引用、新安装、新共享引用、目录替换和无法确认文件占用的情况。

`script/test_agent_workflow.sh` 验证数据审查不会自动提交、空选择不执行、提交选择不随新扫描扩张、互斥门禁及拒绝结果反馈。`script/test_software_workflows.sh` 覆盖排队卸载的数据身份绑定。

补充回归：`test_uninstall_residue.sh` 以隔离目录验证普通软件历史的可选预览、应用删除后名称归属保留、普通 CLI 的配置/历史残留、未记录的 Bundle-ID 残留（含小体积偏好）、扫描发布默认不选、重装后拒绝、真实项目保护以及实际移入测试废纸篓。`test_cli_uninstall_request.sh` 和 `test_agent_program_removal.sh` 覆盖卸载成功后的数据审查入口。

这些是隔离夹具和代码路径验证，不代表已经删除本机 Cursor 数据，也不代表完成了桌面操作测试。

本机只读补验（2026-10-20）：Cursor 数据计划原先因 Codex 项目信任配置中的主目录路径而全部受保护；限制到实际 MCP/Skill 引用后，识别出 22 个可选根、约 17.57 GiB 已分配空间，共享插件部分仍保留。此次仅查看计划，没有删除现有 Cursor 数据。

合并 `cce0a4e`（1.0.16）后的兼容回归：保留白名单不可读时停止扫描、启动器仅解除链接及独立 `AgentRemovalService` 的验证；普通 CLI 的已知 Agent 归属进入一次共享选择审查，不再重复打开旧确认。Agent 工作流、软件/CLI 卸载、残留、扫描及目录排序的隔离测试通过。

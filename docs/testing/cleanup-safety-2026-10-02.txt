Nori 清理能力测试记录
日期：2026-10-02
环境：macOS 27.0.1 / arm64；Swift 编译采用可用的 CommandLineTools 和 macOS 26.5 SDK。

范围与方法
1. 生产清理扫描/删除代码在隔离目录中处理真实文件；外部包管理器、系统维护、Docker、Simulator 和 Time Machine 的破坏性命令使用录制桩验证参数和失败路径。
2. Nori 原生界面执行只读扫描；在专用 ui-cache 目录走完添加规则、确认可再生内容、保留 7 天预览、手动移入废纸篓、重新预览、开启规则自动执行、停用与删除规则。
3. 用 Finder“放回原处”恢复两份真实清理的测试文件，并逐字节核对内容；近期文件保持原样。未清空用户废纸篓。
4. 真实 npm Agent 安装在一次性 HOME/prefix 中，通过生产 AgentCLIService 识别及卸载；真实运行状态保护由隔离测试快照验证。没有登录 Agent 账号或发起付费推理。

发现与修复
A. 定时扫描等待期间停用/撤销/修改规则，旧计划仍可执行。删除前重新核对完整规则和嵌套规则目录集合；变化时放弃旧计划并取消限频，下一轮重新扫描。手动清理最终入口也核对当前规则。
B. 自动清理完成后仍显示已删除候选的旧预览。执行结束清空该规则预览；回归直接运行生产执行方法验证。
C. 开发工具卸载桥接将 --all 等选项接受为包名。调用任何包管理器前拒绝以 - 开头的包名；7 个卸载管理器均验证拒绝选项和命令元字符。

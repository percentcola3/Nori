# Nori 1.0.9

**Early development: Nori is not yet stable.** Review cleanup selections and keep backups of important data. macOS 13+ remains supported.

- Configure conversation and artifact retention independently for each Agent, with a default of 90 days or an option to never clean. Remove the oversized aggregate panel and keep storage summaries within Agent groups.
- Expand Agent and service coverage to 29 definitions, including Aider, Goose, Cline, Continue and Playwright. Inspect expired conversations and temporary artifacts, recheck Git worktrees before cleanup, and move user data to Trash while permanently deleting safe rebuildable caches. Add a backed-up local config switch for Codex's experimental thread-store compression.
- Improve tab responsiveness after Agent scans by caching selection and storage summaries and preparing totals in the background.
- Add continuous keep-awake in Settings, with optional display wake, low-battery and critical-temperature protection, and floating-island status. There is no duration limit; manual stop or app exit releases the sleep assertions, and closing the lid still allows sleep.
- Show Git branches, ahead/behind counts and sync controls directly in directory rows, with a recognizable orange Git icon. Click a branch name to switch local branches; sync uses fast-forward-only upstream pulls. Counts reflect the last fetch, and repository status reads use bounded concurrency and cancellation.
- Preserve the existing App signing identity and Sparkle update public key.

Download `Nori-arm64.dmg` for Apple silicon or `Nori-x86_64.dmg` for Intel. Existing Sparkle-enabled releases can detect this update. The self-signed App is not Apple-notarized; cross-version privacy permission retention on another Mac has not yet been verified.

# Nori 1.0.9 · 中文

**早期开发阶段，目前尚不够稳定。** 清理前请核对所选内容，并保留重要数据备份。继续支持 macOS 13+。

- 每个 Agent 独立设置对话和产物保留策略，默认 90 天，也可选择永不清理。移除过大的总览面板，容量摘要保留在各 Agent 分组内。
- 扩展至 29 种 Agent 与服务定义，新增 Aider、Goose、Cline、Continue 和 Playwright 等。识别过期会话和临时产物，清理前复核 Git worktree；用户数据移入废纸篓，可重建的安全缓存永久删除。新增 Codex 实验性会话存储压缩的本地配置开关，修改前备份配置。
- 缓存所选数据和容量汇总，在后台预计算统计，改善 Agent 扫描后切换页面的响应速度。
- 设置页新增无时限的持续唤醒，可选择保持屏幕亮起，并支持低电量、严重温度保护和灵动岛状态展示。手动关闭或退出应用时释放睡眠限制，合盖仍会睡眠。
- 目录行直接展示 Git 分支、领先/落后数量和同步按钮，使用清晰的橙色 Git 标识。点击分支名切换本地分支，同步仅快进拉取上游；数量基于最近一次抓取，仓库状态读取限制并发并支持取消。
- 保持既有 App 签名身份与 Sparkle 更新公钥不变。

Apple 芯片下载 `Nori-arm64.dmg`，Intel 下载 `Nori-x86_64.dmg`。已支持 Sparkle 的版本可检测本次更新。应用使用固定自签名证书，未经 Apple 公证；另一台 Mac 上的跨版本隐私授权保留尚未验证。

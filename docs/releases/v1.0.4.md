# Nori 1.0.4

**Early development: Nori is not yet stable.** Review cleanup selections and keep backups of important data. macOS 13+ remains supported.

- Creating a scheduled cleanup task now enables it and starts an immediate check. Manually selected folders are confirmed in the creation form, before the task is created. Existing paused tasks remain paused when duplicate folders are skipped.
- Run scheduled cleanup through the native Trash executor instead of the slow per-file shell pipeline. Recheck authorized root identities, direct-child scope, file identities, nested writes, protected content, and open files before moving items. Record bytes for items actually moved, including partial cleanup results.
- Persist the last check time even when no files qualify, and simplify task cards: one cumulative statistic, shorter dates, expandable policy and folder details, and a compact actions menu.
- Place System Data after the other cleanup groups.
- Refresh the English and Chinese READMEs and all sixteen referenced screenshots. Correct screenshot fixture grouping so synthetic user caches appear in their proper categories.
- Preserve the existing App signing identity and Sparkle update public key.

Download `Nori-arm64.dmg` for Apple silicon or `Nori-x86_64.dmg` for Intel. Existing Sparkle-enabled releases can detect this update. The self-signed App is not Apple-notarized; cross-version privacy permission retention on another Mac has not yet been verified.

# Nori 1.0.4 · 中文

**早期开发阶段，目前尚不够稳定。** 清理前请核对所选内容，并保留重要数据备份。继续支持 macOS 13+。

- 定时清理任务创建成功后默认启用，并立即检查一轮。手动选择的目录在创建面板里确认用途，创建后无需再开启开关；跳过重复目录时保留已有任务的暂停状态。
- 自动清理改用原生废纸篓执行通道，避免大量文件逐项调用脚本造成超时。移动前重新验证授权目录身份、直接子项范围、文件身份、目录内的新写入、受保护内容与文件占用；部分清理也按实际移入的项目统计容量。
- 没有符合条件的文件时也保存上次检查时间。任务卡片只保留一条累计统计，缩短日期，折叠策略与目录详情，并使用紧凑操作菜单。
- 清理结果中的“系统数据”分组排在其他分组之后。
- 更新中英文 README 及其引用的全部 16 张截图；修正截图示例用户目录的分组，避免把用户缓存误显示为系统数据。
- 保持原来的 App 固定签名身份和 Sparkle 更新公钥。

Apple 芯片下载 `Nori-arm64.dmg`，Intel 下载 `Nori-x86_64.dmg`。已有支持 Sparkle 的版本可通过 App 更新检查检测本版。App 使用自签名，未经 Apple 公证；尚未在另一台 Mac 验证跨版本隐私授权保留。

# Nori 1.0.20

- Recommend independently old npm `content-v2` cache units even when their parent cache remains active. Restrict the new split recommendation to content units, keep recent branches unselected, and retain the seven-day default threshold for configured npm caches inside temporary directories.
- Strengthen protection for relocated Gradle, Cargo and other dependency stores. Preserve physical macOS path identities, refresh ownership after alias changes, and reject stale deletion plans.
- Reduce repeated metadata checks during large user-temporary-tree previews while retaining per-item content, permission and occupancy checks and fresh execution checks.
- Preserve per-path selections when saving and restoring scan snapshots, and show the mixed-selection state on cleanup group headers.
- Improve npm/pnpm inventory parsing, isolate package-manager query failures, retain unknown-size tool records for manual review, and use consistent terminal environments for developer scans and actions.
- Localize additional configuration and keep-awake errors, and expand cleanup, presentation and release regression coverage.

The seven-day rule applies to default recommendations and automatic cleanup; explicit manual cache cleanup retains its existing behavior. Scan snapshots do not immediately persist later checkbox changes. Scan-read activity attribution is currently process-local. The installer-scanning bridge is not yet exposed in the cleanup interface, and existing Swift 6 migration warnings remain.

Download `Nori-arm64.dmg` for Apple silicon or `Nori-x86_64.dmg` for Intel. Supports macOS 13+. Retains the existing self-signed App certificate and Sparkle update key; not Apple-notarized. Cross-version permission retention on another Mac remains unverified.

# Nori 1.0.20 · 中文

- npm 缓存按独立旧 `content-v2` 单元推荐，父缓存活跃时仍能识别旧内容；新增细分推荐仅针对内容单元，近期活跃分支保持未选，自定义 npm 缓存位于临时目录时仍保留七天默认门槛。
- 加强迁移后的 Gradle、Cargo 等依赖库保护：保留 macOS 物理路径身份，归属别名变化后重新检查，拒绝陈旧删除计划。
- 减少大型用户临时目录预览中的重复元数据检查，同时保留逐项内容、权限、占用检查和执行前实时复核。
- 扫描快照保存与恢复逐路径选择，清理分组头正确显示部分选中状态。
- 改进 npm/pnpm 清单解析、隔离不同管理器查询失败、保留未知容量的工具记录供人工复核，并统一开发工具扫描与执行的终端环境。
- 补齐配置和保持唤醒错误的本地化，扩展清理、呈现及发布回归覆盖。

七天规则用于默认推荐和自动清理；明确的手动缓存清理保留原有行为。扫描快照不会即时保存后续勾选变化；扫描读取的活动归因目前仅在进程内保留。安装包扫描桥接尚未接入清理界面，既有 Swift 6 迁移警告仍保留。

Apple 芯片下载 `Nori-arm64.dmg`，Intel 下载 `Nori-x86_64.dmg`。支持 macOS 13+。保持原有 App 自签名证书和 Sparkle 更新公钥，未经 Apple 公证；另一台 Mac 上的跨版本权限保留尚未验证。

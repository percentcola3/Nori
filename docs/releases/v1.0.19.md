# Nori 1.0.19

- Unify process inspection across Nori and restore native inventory safeguards: shared read-only file scanning, native CLI ownership receipts and inventory protections return as one implementation, joined by complete PID inspection, project-directory search, resource-panel access and precise process identity checks.
- Fix Spotlight search fallback so separator-spanning names match subtokens, and strip the `@` prefix from path queries.
- Unify themed control contrast across menus, command buttons and settings selections with paired text and surface colors in both appearances, keeping native picker bindings and disabled states.
- Stabilize the shared capacity badge by pairing badge text with opaque theme surfaces in normal and prominent states.
- Extend release regression coverage for process inspection, file scanning, process sampling, runtime store aggregation and command-line tool inventory; record FSearch baseline and metadata/memory A/B research notes behind these changes.

Download `Nori-arm64.dmg` for Apple silicon or `Nori-x86_64.dmg` for Intel. Supports macOS 13+. Retains the existing self-signed App certificate and Sparkle update key; not Apple-notarized. Cross-version permission retention on another Mac remains unverified.

# Nori 1.0.19 · 中文

- 统一 Nori 的进程检查并恢复原生清单防护：共享只读文件扫描、原生 CLI 归属凭据与清单保护回归为同一实现，并新增完整 PID 检查、项目目录搜索、资源面板访问和精确的进程身份校验。
- 修复 Spotlight 搜索回退，分隔符跨越的名称可按子词元匹配；路径查询不再保留 `@` 前缀。
- 菜单、命令按钮与设置选择控件统一使用配对的文字与表面颜色，在深浅两种外观下都保证文本对比度，同时保留原生选择器绑定和禁用态。
- 共享容量徽章在普通与突出状态下均与不透明主题表面配对，稳定对比度。
- 将进程检查、文件扫描、进程采样、运行时存储聚合和命令行工具清单接入发布回归；记录支撑这些改动的 FSearch 基线与元数据/内存 A/B 研究笔记。

Apple 芯片下载 `Nori-arm64.dmg`，Intel 下载 `Nori-x86_64.dmg`。支持 macOS 13+。保持原有 App 自签名证书和 Sparkle 更新公钥，未经 Apple 公证；另一台 Mac 上的跨版本权限保留尚未验证。

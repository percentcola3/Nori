# Nori 1.0.15

- Replace stacked island metrics with compact gauges. Center values inside the dials, place names below, and keep upload/download readings and a small network trend. Reduce space in both top and side layouts.
- Finish bandwidth tests automatically in about 15 seconds, retain download/upload and latency results, and show a short download-speed assessment. Add a 20-second timeout for stalled commands and refine the Ping and speed-test spacing.
- Refresh Bluetooth battery readings when audio devices connect or change, with short retries for delayed battery reports. Retain the normal one-minute refresh interval after settling.
- Remember menu bar collection settings, selected apps, tray visibility and collapse state across Nori restarts and updates. Reapply the saved state after waking, display changes and application launches; temporary expansion and shutdown preserve the saved choices.

Download `Nori-arm64.dmg` for Apple silicon or `Nori-x86_64.dmg` for Intel. Supports macOS 13+. This release retains the fixed self-signed App certificate and Sparkle update key and is not Apple-notarized. Real headset reconnection latency and cross-version permission retention on another Mac remain unverified.

# Nori 1.0.15 · 中文

Apple 芯片下载 `Nori-arm64.dmg`，Intel 下载 `Nori-x86_64.dmg`。支持 macOS 13+。本版保持固定 App 自签名证书和 Sparkle 更新公钥，未经 Apple 公证；真实耳机重连时延和另一台 Mac 上的跨版本权限保留尚未验证。

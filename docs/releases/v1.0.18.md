# Nori 1.0.18

- Reuse a bounded administrator session during each app run, authorizing on first use or from Settings. The broker accepts only bundled, allowlisted operations and checks the calling app's identity; destructive actions retain their own confirmations.
- Add an explicit memory cache reclaim action with refreshed memory and swap readings, cancellation and failure feedback.
- Expand uninstall data review to owner-named single-file configurations and Homebrew download/log residues. Reuse application metadata during residue scans.
- Refine the sea-blue window glass, atmosphere, app icon and floating island tint, with stronger text contrast on content surfaces.
- Extend release regression coverage for administrator-session protocol, client, state and memory cache reclaim; audit session-owned temporary-file cleanup with exact call and ownership checks.

Download `Nori-arm64.dmg` for Apple silicon or `Nori-x86_64.dmg` for Intel. Supports macOS 13+. Retains the existing self-signed App certificate and Sparkle update key; not Apple-notarized. Cross-version permission retention on another Mac remains unverified.

# Nori 1.0.18 · 中文

- 管理员会话在每次应用运行期间限时复用，可在首次执行时授权或从设置主动授权。辅助程序只接受应用内置且在白名单中的操作，并核验调用应用身份；删除操作保留各自的确认流程。
- 增加独立的内存缓存回收操作，刷新内存与交换空间读数，并提供取消和失败反馈。
- 卸载数据复核扩展至归属明确的单文件配置、Homebrew 下载缓存与日志残留；残留扫描复用应用元数据。
- 调整海蓝色窗口玻璃、氛围层、应用图标及灵动岛色调，增强内容面板文字对比度。
- 将管理员会话协议、客户端、状态和内存缓存回收接入发布回归；以精确调用和归属约束审计会话自建临时文件的清理。

Apple 芯片下载 `Nori-arm64.dmg`，Intel 下载 `Nori-x86_64.dmg`。支持 macOS 13+。保持原有 App 自签名证书和 Sparkle 更新公钥，未经 Apple 公证；另一台 Mac 上的跨版本权限保留尚未验证。

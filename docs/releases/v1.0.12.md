# Nori 1.0.12

- Refine the island's compact layout and expansion animation. A gear opens the existing Nori Settings panel directly, including on hardware-notch and side layouts.
- Show the collected-icon slot only when collection is enabled and icons are available. Simplify its hover drawer and add an optional recovery tray icon for macOS 27; older systems retain the separator's required recovery control.
- Rework network diagnostics into Ping and bandwidth tabs. Ping shows latency, packet loss and jitter; the bandwidth tab adds a speed gauge, live interface throughput while testing, and final download/upload results.
- Allow a measurement to continue while the island collapses or another metric opens. Show a busy indicator on the network tile and retain results for reopening. Extend the system bandwidth test timeout from 45 to 120 seconds. Stop remains available; opening the main window, disabling the island or quitting Nori cancels the test.

Download `Nori-arm64.dmg` for Apple silicon or `Nori-x86_64.dmg` for Intel. Nori supports macOS 13+. Menu bar collection on macOS 27 remains experimental and uses a private system interface; original icon interaction requires Accessibility permission. Cross-version physical-machine compatibility remains unverified. This release retains the fixed self-signed App certificate and Sparkle update key and is not Apple-notarized.

# Nori 1.0.12 · 中文

- 精简灵动岛尺寸并调整展开动画。齿轮直接打开现有 Nori 设置面板，覆盖刘海屏及侧边布局。
- 收纳启用且存在图标时才显示缩略图入口，简化悬停网格；macOS 27 可选择是否显示菜单栏恢复图标，旧系统保留分隔条所需的恢复入口。
- 网络检测改为 Ping／带宽两个选项。Ping 展示延迟、丢包率和抖动；带宽检测增加速度仪表盘，运行时展示网卡实时流量，完成后展示下载／上传结果。
- 收起灵动岛或切换指标时，检测继续在后台运行；网络指标显示忙碌状态，再次打开可查看结果。系统带宽测速超时从 45 秒延长至 120 秒。保留停止操作；打开主窗口、关闭灵动岛或退出 Nori 时取消检测。

Apple 芯片下载 `Nori-arm64.dmg`，Intel 下载 `Nori-x86_64.dmg`。支持 macOS 13+。macOS 27 收纳仍为私有系统接口实验模式，操作原图标需要辅助功能权限；跨版本实机兼容性尚未验证。本版保持固定 App 自签名证书和 Sparkle 更新公钥，未经 Apple 公证。

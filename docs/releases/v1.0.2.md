# Nori 1.0.2

**Early development: Nori is not yet stable.** Review cleanup selections and keep backups of important data. This release improves cleanup feedback and permission handling; macOS 13+ remains supported.

- Batch administrator cleanup into one authorization request per cleanup, with a choice to include or skip administrator items before deletion starts.
- Show real file and directory activity during scanning and cleanup, including Agent scans and administrator cleanup.
- Keep the working SVG visible; hide buttons during success feedback, then return to the idle SVG and the original scan button after about three seconds.
- Center failure descriptions and show disk-analysis coverage issues with affected paths, system errors, and actionable guidance.
- Improve glass window edges, scan/rescan controls, mascot alignment, screenshot editing cursors, and Agent cleanup safeguards.
- Preserve the existing App signing identity and Sparkle update public key.

Download `Nori-arm64.dmg` for Apple silicon or `Nori-x86_64.dmg` for Intel. Updates from 1.0.1 can be detected through Nori's update checks. The self-signed App is not Apple-notarized.

# Nori 1.0.2 · 中文

**早期开发阶段，目前尚不够稳定。** 清理前请核对所选内容，并保留重要数据备份。本版改进清理反馈与权限处理，继续支持 macOS 13+。

- 管理员清理合并为每次清理一次授权，删除前可选择包含或跳过管理员项目。
- 扫描和清理展示真实文件、目录变化，包含 Agent 扫描与管理员清理。
- 工作过程中保留 SVG；成功动画期间隐藏按钮，约三秒后返回闲置 SVG 与首次进入时的扫描按钮。
- 清理失败说明居中；磁盘分析未覆盖完整时提供相关路径、系统错误和处理建议。
- 改进玻璃窗口边缘、扫描与重新扫描入口、角色对齐、截图编辑鼠标样式，以及 Agent 清理保护逻辑。
- 保持原来的 App 固定签名身份和 Sparkle 更新公钥。

Apple 芯片下载 `Nori-arm64.dmg`，Intel 下载 `Nori-x86_64.dmg`。1.0.1 可通过 App 更新检查检测本版。App 使用自签名，未经 Apple 公证。

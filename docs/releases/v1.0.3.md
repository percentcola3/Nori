# Nori 1.0.3

**Early development: Nori is not yet stable.** Review cleanup selections and keep backups of important data. This release improves Trash cleanup, directory navigation, disk analysis, and developer tools; macOS 13+ remains supported.

- Treat Trash entries as user-discarded items: application bundles, embedded databases, and durable content names no longer hide their size or prevent cleanup. Preserve file identity, permission, occupancy, and device checks; framework symlinks are removed without following their targets.
- Avoid counting an uninstalled app's data root again when its cache descendants are already listed for cleanup.
- Reclaim Nori's own regenerable caches and old temporary files, compress cleanup inventories, and keep large per-file analysis trees in bounded session memory to reduce Nori's disk usage.
- Add WeChat 4.x cache and temporary-file cleanup. Chat images and videos require manual selection; message databases, settings, chat documents, and backups remain protected.
- Add a Directory workspace with path navigation, search, allocated disk sizes, file operations, drag and drop, and directory rules for automatic cleanup. Improve disk-analysis coverage, duplicate-file and similar-image review, and responsiveness.
- Expand developer workflows for toolchains, packages, shell configuration, network settings, SSH, and Git. Add a command-line tools inventory to the Software page.
- Improve glass navigation, island metrics, background metric sampling, cleanup performance, and uninstall feedback and associated-data discovery.
- Preserve the existing App signing identity and Sparkle update public key.
- Use the renamed `percentcola3/Nori` repository for new update feeds and downloads. Existing releases can still reach updates through GitHub's redirect from the old repository address.

Download `Nori-arm64.dmg` for Apple silicon or `Nori-x86_64.dmg` for Intel. Existing Sparkle-enabled releases can detect this update through Nori's update checks. The self-signed App is not Apple-notarized. Cross-version privacy permission retention on another Mac has not yet been verified.

# Nori 1.0.3 · 中文

**早期开发阶段，目前尚不够稳定。** 清理前请核对所选内容，并保留重要数据备份。本版改进废纸篓清理、目录管理、磁盘分析和开发者工具，继续支持 macOS 13+。

- 废纸篓按用户已丢弃的条目处理：应用包、内置数据库和持久数据名称不再阻止容量统计与清理。保留文件身份、权限、占用和设备检查；框架中的符号链接只删除链接本身，不跟随到目标。
- 已列出缓存子项时，不再重复计入已卸载应用的数据父目录。
- 支持清理 Nori 自身的可再生缓存与旧临时文件，压缩清理清单，并将大型逐文件分析树保留在有容量限制的会话内存中，减少 Nori 自身的磁盘占用。
- 增加微信 4.x 缓存和临时文件清理。聊天图片、视频需手动勾选；消息数据库、设置、聊天文件与备份继续受保护。
- 增加目录工作区，支持路径导航、搜索、实际硬盘占用、文件操作、拖放和自动目录清理规则；改进磁盘分析覆盖、重复文件与相似图片审查及响应速度。
- 扩展开发者工作流，涵盖工具链、软件包、Shell 配置、网络设置、SSH 与 Git；软件页新增命令行工具清单。
- 改进玻璃导航、灵动岛指标、后台指标采样、清理性能，以及卸载反馈和关联数据识别。
- 保持原来的 App 固定签名身份和 Sparkle 更新公钥。
- 新版更新源与下载链接使用更名后的 `percentcola3/Nori` 仓库；旧版仍可通过 GitHub 对旧仓库地址的重定向获取更新。

Apple 芯片下载 `Nori-arm64.dmg`，Intel 下载 `Nori-x86_64.dmg`。已有支持 Sparkle 的版本可通过 App 更新检查检测本版。App 使用自签名，未经 Apple 公证；尚未在另一台 Mac 验证跨版本隐私授权保留。

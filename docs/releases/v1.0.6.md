# Nori 1.0.6

**Early development: Nori is not yet stable.** Review cleanup selections and keep backups of important data. macOS 13+ remains supported.

- Separate installation size, identified Agent data, reclaimable garbage and preserved data. Agent and Software pages share the same data measurements, deduplicate shared paths, and mark incomplete measurements. Sessions, history and credentials are not automatically counted as garbage; manually selected data has a separate deletion amount.
- Uninstall a selected CLI or desktop installation directly from the Agent page. Remove only that installation first, then separately confirm cleanup of identified Agent data. Running programs require close consent; newly started data consumers are checked again before cleanup. Failed removal never authorizes data deletion, and shared Skill/MCP bodies retain their ownership safeguards.
- Fix CLI uninstall process ownership across supported installations. Closing a separately installed CLI no longer targets its desktop application. Recheck installation and process identities before removal, and require renewed consent if the tool starts while confirmation is open.
- Reduce administrator cleanup preparation and deletion overhead with indexed batches and bounded background workers. Coalesce progress and move retry reconciliation off the UI thread to keep the app responsive during large cleanups.
- Reduce repeated Agent configuration and Skill reads within a scan, retain cancellation and time limits, and show uninstalled Agent data without selecting it automatically.
- Complete short background commands promptly in the timeout fallback while preserving exit codes, deadlines and process-group cleanup.
- Refactor domain workflows and remove unused code. Preserve the existing App signing identity and Sparkle update public key.

Download `Nori-arm64.dmg` for Apple silicon or `Nori-x86_64.dmg` for Intel. Existing Sparkle-enabled releases can detect this update. The self-signed App is not Apple-notarized; cross-version privacy permission retention on another Mac has not yet been verified.

# Nori 1.0.6 · 中文

**早期开发阶段，目前尚不够稳定。** 清理前请核对所选内容，并保留重要数据备份。继续支持 macOS 13+。

- 分开显示安装本体、已识别 Agent 数据、可清理垃圾和保留数据。Agent 页与软件页共用关联数据统计，共享路径去重，未完成的计量明确标记。会话、历史和凭据不自动计入垃圾；用户手动选中的数据另行显示本次删除容量。
- Agent 页可直接卸载所选 CLI 或桌面安装。先仅移除这一份安装，再单独确认已识别 Agent 数据清理。程序运行中需确认关闭；清理前重新检查新启动的数据使用者。卸载失败不进入数据删除，共享 Skill 与 MCP 本体继续保留归属保护。
- 修复支持的 CLI 安装在卸载时的进程归属判断。关闭独立 CLI 不会误处理桌面应用；卸载前重新核对安装与进程身份，确认期间新启动的工具需重新确认关闭。
- 优化管理员清理的准备与删除阶段，使用索引批次及有限后台并发，合并进度更新，并将重试结果核对移出界面线程，减少大批量清理时的卡顿。
- 减少单次 Agent 扫描内重复读取配置和 Skill 信息，保留取消与时限控制；显示已卸载 Agent 的关联数据，默认不勾选。
- 改善后台短命令在超时工具中的响应速度，保留原有退出码、时限和进程组清理。
- 整理领域工作流并移除无用代码，保持现有 App 固定签名身份和 Sparkle 更新公钥。

Apple 芯片下载 `Nori-arm64.dmg`，Intel 下载 `Nori-x86_64.dmg`。已有支持 Sparkle 的版本可通过 App 更新检查检测本版。App 使用自签名，未经 Apple 公证；尚未在另一台 Mac 验证跨版本隐私授权保留。

# Nori 1.0.0

Nori is an open-source, native macOS companion for reclaiming disk space and keeping your Mac tidy. Inspired by [Mole](https://github.com/tw93/Mole), Nori brings cleanup, developer tools and everyday utilities into a lightweight Swift/SwiftUI app, with a Dynamic Island-style desktop companion and native Liquid Glass on macOS 26.

## In this release

- **Reclaim space with a preview.** Quick and deep scans cover caches, logs, Trash, orphaned leftovers and developer artifacts. Review the paths and risk labels before cleaning. Macs with accumulated development caches may reclaim tens of gigabytes; results depend on your machine and selections.
- **Clean development environments.** Find Xcode DerivedData, Swift package downloads, Carthage files, simulator caches, Node package/build caches, Python download caches, Gradle build artifacts, Cargo downloads, Go caches and more. Docker cleanup uses Docker's own prune commands. Current/default Node versions and manager-owned runtimes receive additional protection; development cache cleanup defaults to seven days of inactivity.
- **Keep AI tools tidy.** Recognize Claude Code/Desktop, Codex CLI/App, Cursor/CLI, GitHub Copilot CLI, Gemini CLI, Antigravity, OpenCode, Grok CLI, pi, Kimi, Factory Droid, Devin, Windsurf, Chrome DevTools MCP, Qoder, Kiro, Trae, Zed, Warp, Amp and Crush. Review disposable caches, logs and obsolete versions separately from sessions, checkpoints, memories, credentials and worktrees. Inspect Skills, MCP registrations and CLI installations, including shared consumers. Running AI cleanup permanently deletes selected files immediately, without a second confirmation.
- **Set up folder housekeeping.** Opt-in rules for your selected folders use age and size limits. Scheduled cleanup moves matching direct children to Trash, with a preview and safety checks.
- **Use a local clipboard history.** Opt in to text, links, files and images; filter, pin and copy items again. History stays on your Mac.
- **Capture and frame screenshots.** Configurable shortcuts default to `⌘⇧S` for region/window capture and `⌘⇧R` for fixed-ratio capture. Add gradients and frames, change aspect ratio and export PNG/JPEG at 1× or 2×.
- **Watch your Mac from the island.** Glance at CPU and memory, inspect processes, disk usage, ports and network activity, and review large files, duplicates, similar images and app leftovers. Includes 12 interface languages and transparency/motion accessibility fallbacks.

See the [English README](https://github.com/percentcola3/sweep#readme) and [中文介绍](https://github.com/percentcola3/sweep/blob/main/README.zh-CN.md) for feature details and screenshots in both languages.

## Download and install

Requires **macOS 13 or later**. Choose **Nori-arm64.dmg** for Apple silicon or **Nori-x86_64.dmg** for Intel. Open the DMG and drag Nori.app into `/Applications`.

The app uses the project's long-lived signing certificate. It is **self-signed and not Apple-notarized**. If macOS blocks first launch, use **System Settings → Privacy & Security → Open Anyway** where available. Do not disable Gatekeeper or install the publisher's certificate.

Cleaning and screenshots need the corresponding system permissions. Public releases keep the same certificate, `com.nori.app` bundle identifier and designated requirement. Moving from a development/ad-hoc build, an earlier ForgeSweep bundle or a different signing certificate may require reauthorization once. Fixed signing preserves code identity; cross-version privacy permission retention has not yet been verified on a separate Mac and depends on macOS.

`RELEASE-IDENTITY.txt` records the source commit, app version and verified signing identity. Check all downloaded assets in the same directory:

```bash
shasum -a 256 -c SHA256SUMS
```

# Nori 1.0.0 · 中文

Nori 是开源、原生、轻量的 macOS 增强工具，帮助释放磁盘空间并守护你的 Mac。我们受到 [Mole](https://github.com/tw93/Mole) 的启发，以 Swift/SwiftUI 构建桌面灵动岛，并在 macOS 26 使用原生液态玻璃。

## 本次发布

- **先预览，再清理。** 快速/深度扫描覆盖缓存、日志、废纸篓、残留与开发者产物。确认路径与风险等级后再清理；长期积累开发缓存的 Mac 有机会一次释放几十 GB，实际空间取决于你的环境与选择。
- **开发者环境清理。** 支持 Xcode DerivedData、Swift 包下载、Carthage、模拟器缓存、Node 包管理器与构建缓存、Python 下载缓存、Gradle 构建产物、Cargo 下载、Go 缓存等。Docker 通过官方 prune 命令清理；当前/默认 Node 版本与包管理器拥有的运行时受到额外保护，开发缓存默认保留最近七天的活动数据。
- **AI Agent 专项整理。** 识别 Claude Code/Desktop、Codex CLI/App、Cursor/CLI、GitHub Copilot CLI、Gemini CLI、Antigravity、OpenCode、Grok CLI、pi、Kimi、Factory Droid、Devin、Windsurf、Chrome DevTools MCP、Qoder、Kiro、Trae、Zed、Warp、Amp、Crush。缓存、日志与旧版本和会话、检查点、记忆、凭据、工作树分别提示风险；同时查看 Skills、MCP 注册和 CLI 安装及共享关系。执行 AI 清理会立即永久删除所选文件，不会再弹出二次确认。
- **目录定时清理。** 为自己选择的目录启用按时间与大小匹配的规则，预览后定时将符合规则的直接子项移入废纸篓，并执行安全校验。
- **本地剪贴板历史。** 按需开启文字、链接、文件和图片历史，支持筛选、置顶与再次复制，数据留在本机。
- **截图与美化。** 默认 `⌘⇧S` 截取区域/窗口，`⌘⇧R` 按固定比例截图；快捷键可自定义。支持渐变、边框、比例调整和 PNG/JPEG 的 1×/2× 导出。
- **灵动岛守护。** 查看 CPU、内存、进程、磁盘、端口与网络活动，分析大文件、重复文件、相似图片和应用残留。支持 12 种界面语言，以及减少透明度/动态效果回退。

## 下载与安装

支持 **macOS 13 及以上**。Apple 芯片下载 **Nori-arm64.dmg**，Intel 下载 **Nori-x86_64.dmg**，打开后将 Nori.app 拖入 `/Applications`。

本版复用项目长期固定的签名证书，**属于自签名，未经 Apple 公证**。首次启动若被 macOS 拦截，可在“系统设置 → 隐私与安全性”中选择“仍要打开”；不要关闭 Gatekeeper，也无需安装维护者的证书。

清理与截图需要相应系统授权。后续公开版本保持同一证书、`com.nori.app` Bundle ID 和 designated requirement。从开发版、ad-hoc、旧 ForgeSweep Bundle 或其他证书迁移时，可能需要重新授权一次。固定签名保持代码身份；跨版本隐私授权保留尚未在另一台 Mac 验证，也受 macOS 行为影响。

`RELEASE-IDENTITY.txt` 记录源码提交、版本与已验证的签名身份。将所有附件放在同一目录，运行 `shasum -a 256 -c SHA256SUMS` 校验。

# Nori 1.0.21

- Keep cleanup discovery and cache revalidation responsive with an authenticated, signed read-only worker. Cancelled, timed-out or invalid worker requests stop without falling back to scanning on the interface thread.
- Prepare large cleanup selections and presentation snapshots in the background, preserve partial selections, and reject obsolete asynchronous results.
- Start selected uninstall-leftover cleanup directly. Other application-data review keeps its existing confirmation and execution checks.
- Retry recoverable cleanup failures silently, with at most three attempts per original target in one cleanup task, including the first attempt. Confirmed removals are not repeated; remaining failures no longer open a failure or retry dialog.
- Reuse only the same live administrator session for retries. Missing or invalid execution reports stop rather than replaying an operation with an unknown outcome. Preserve the original target identities, permissions, whitelist, occupancy and content protections.
- Quietly retain targets proven to be protected by filesystem flags or a read-only volume. Keep independently eligible contents separate and report actual reclaimed space without counting failed attempts as deletions.
- Add bounded local cleanup diagnostics and expand regression coverage for process isolation, cancellation, partial results, retry limits and inventories of 100,000 targets.

Age-restricted work that needs a fresh activity review stops instead of reusing stale age evidence. Tool commands with uncertain side effects are not automatically replayed. Cleanup diagnostics remain local and bounded.

Download `Nori-arm64.dmg` for Apple silicon or `Nori-x86_64.dmg` for Intel. Supports macOS 13+. Retains the existing self-signed App certificate and Sparkle update key; not Apple-notarized. Cross-version permission retention on another Mac remains unverified.

# Nori 1.0.21 · 中文

- 清理发现和缓存复核改由经过身份验证、独立签名的只读 worker 执行，减少界面卡顿。取消、超时或协议异常时停止，不回退到界面主线程扫描。
- 大型清理选择和展示快照在后台准备，保留部分选中状态，拒绝过期异步结果覆盖新状态。
- 勾选的卸载垃圾直接进入清理流程；其他应用数据复核仍保留原有确认及执行检查。
- 可恢复的清理失败静默重试，同一次清理任务中每个原始目标最多尝试三次，含首次。已确认删除的目标不重复处理；剩余失败不再弹出失败或再次清理提示。
- 管理员重试仅复用同一个仍存活的授权会话。执行报告缺失或无效时停止，避免重放结果未知的操作；保留原始目标身份、权限、白名单、占用及内容保护。
- 静默保留已证实受文件系统标志或只读卷限制的目标，区分其中独立符合条件的内容，按真实删除结果统计释放空间，不把失败尝试计为删除。
- 增加有界本地清理诊断，并扩展进程隔离、取消、部分成功、三次上限及十万目标规模的回归覆盖。

需要重新复核活动时间的年龄限定任务会停止，不沿用过期的年龄证据；具有未知副作用的工具命令不会自动重放。清理诊断仅保存在本机，且限制容量。

Apple 芯片下载 `Nori-arm64.dmg`，Intel 下载 `Nori-x86_64.dmg`。支持 macOS 13+。保持原有 App 自签名证书和 Sparkle 更新公钥，未经 Apple 公证；另一台 Mac 上的跨版本权限保留尚未验证。

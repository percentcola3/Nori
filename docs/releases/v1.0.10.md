# Nori 1.0.10

**Early development: Nori is not yet stable.** Review cleanup selections and keep backups of important data. macOS 13+ remains supported.

- Unify Skill and MCP resource management across Agents. Search resources by name, path or Agent, inspect shared sources and bindings, and select sources or bindings independently.
- Unlink selected directory links and configuration registrations while retaining the source and other bindings, or move supported local sources to Trash and remove their known bindings. Configuration edits create backups, and running, protected or changed resources are kept.
- Reduce retained memory in disk analysis, clipboard history and image caches, and improve cleanup selection responsiveness.
- Preserve per-Agent conversation and artifact retention settings, the existing App signing identity and Sparkle update public key.

Download `Nori-arm64.dmg` for Apple silicon or `Nori-x86_64.dmg` for Intel. Existing Sparkle-enabled releases can detect this update. The self-signed App is not Apple-notarized; cross-version privacy permission retention on another Mac has not yet been verified.

# Nori 1.0.10 · 中文

**早期开发阶段，目前尚不够稳定。** 清理前请核对所选内容，并保留重要数据备份。继续支持 macOS 13+。

- 统一管理各 Agent 的 Skill 和 MCP 资源。支持按名称、路径或 Agent 搜索，查看共享本体及绑定，并分别选择本体或绑定。
- 可单独解除目录链接和配置注册，保留本体及其它绑定；也可将支持删除的本地本体移至废纸篓，并移除已识别的绑定。修改配置前自动备份，保留运行中、受保护或已变化的资源。
- 降低磁盘分析、剪贴板历史和图像缓存的常驻内存，改善清理选择的响应速度。
- 保留每个 Agent 的对话与产物保留策略，保持既有 App 签名身份与 Sparkle 更新公钥不变。

Apple 芯片下载 `Nori-arm64.dmg`，Intel 下载 `Nori-x86_64.dmg`。已支持 Sparkle 的版本可检测本次更新。应用使用固定自签名证书，未经 Apple 公证；另一台 Mac 上的跨版本隐私授权保留尚未验证。

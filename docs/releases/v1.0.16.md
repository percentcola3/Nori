# Nori 1.0.16

- Speed up large cleanup inventories with indexed rule overlap, file occupancy and scan continuation. Result grouping uses path-only checks once per refresh to keep large Trash lists responsive. Trash previews read allocated-size metadata without opening file contents; validated built-in cache trees reuse in-memory inventories with scoped FSEvents invalidation and periodic refresh. Cancellation is checked during discovery and deletion keeps fresh safety checks.
- Expand developer-cache and project-artifact detection while preserving dependency stores, credentials, live runtime state and unreadable whitelist protection. Installer discovery and execution share the same path and archive policy.
- Add separate complete Agent removal with explicit data review and reversible Trash handling. Improve CLI installation ownership, alias handling, application process shutdown and retry feedback.
- Add configurable page shortcuts, including global activation, conflict detection and recording controls. Refine task-result dialogs, process details and page layouts.

Download `Nori-arm64.dmg` for Apple silicon or `Nori-x86_64.dmg` for Intel. Supports macOS 13+. Retains the existing self-signed App certificate and Sparkle update key; not Apple-notarized. Cross-version permission retention on another Mac remains unverified.

# Nori 1.0.16 · 中文

- 优化大量文件下的清理扫描：规则重叠、文件占用和续扫使用预建索引；结果分组每次刷新只做一次纯路径判断，避免大量废纸篓条目阻塞界面。废纸篓预览读取已分配容量元数据，不打开文件内容。已完整验证的内置缓存树在内存中复用结果，由 FSEvents 按受影响目录失效并定期刷新。发现阶段及时响应取消，删除仍执行实时安全复核。
- 扩展开发缓存和项目产物识别，继续保护依赖仓库、凭据、运行状态及无法读取的白名单；安装包扫描与执行共用路径和归档识别策略。
- 增加独立的 Agent 完整移除及数据复核流程，可逆地移入废纸篓；完善 CLI 安装归属、别名处理、应用进程退出和重试反馈。
- 支持自定义页面快捷键、全局唤起、冲突检测与录制；调整任务结果弹窗、进程详情和各页布局。

Apple 芯片下载 `Nori-arm64.dmg`，Intel 下载 `Nori-x86_64.dmg`。支持 macOS 13+。保持原有 App 自签名证书和 Sparkle 更新公钥，未经 Apple 公证；另一台 Mac 上的跨版本权限保留尚未验证。

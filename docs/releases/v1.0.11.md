# Nori 1.0.11

- Add menu bar icon collection to Nori Settings, with a configurable Collected icons slot in the island. Hover the thumbnail cluster to expand the icon grid; open settings in the existing Nori panel.
- Add clickable island network diagnostics: Ping latency and packet loss for a hostname or IP, plus system upload/download bandwidth testing in Mbps. Tests start manually and can be stopped without interrupting other commands.
- Keep collected icon selection explicit, restore visibility on disable/quit or display/session changes, and reject stale icon targets. Original icon interaction uses Accessibility; native thumbnails use Screen Recording, with app-icon previews as a fallback.
- Retain the Agent history safety protections and disabled official session adapters, fix Swift build compatibility for Gemini/OpenCode, and include the latest Grok uninstall and directory preference fixes.

**Compatibility:** Nori remains an early-development app for macOS 13+. Menu bar collection uses a best-effort separator layout on macOS 13–26. macOS 27 collection is experimental and uses a private system interface; icons are hidden per app, and updates may break support. Original menus open at their macOS location. macOS 13–26 and Intel behavior have not been validated on separate physical machines.

Download `Nori-arm64.dmg` for Apple silicon or `Nori-x86_64.dmg` for Intel. This release keeps the existing App signing identity and Sparkle update key. It uses the project's fixed self-signed certificate and is not Apple-notarized.

# Nori 1.0.11 · 中文

- 菜单栏收纳并入 Nori 设置，灵动岛「快捷指标」可勾选「收纳」。悬停缩略图组展开图标网格，设置入口返回现有 Nori 面板。
- 点击灵动岛「网络」可检测域名或 IP 的 Ping 延迟、丢包率，以及系统上下行带宽（Mbps）。检测手动启动，可随时停止，不中断其它命令。
- 收纳仅作用于明确选择的应用；关闭、退出、显示器或会话变化时恢复展示，拒绝对过期图标猜测操作。操作原图标需要辅助功能权限，真实缩略图使用屏幕录制权限；未授权时回退为应用图标预览。
- 保留 Agent 历史记录安全保护与禁用的官方会话接口，修复 Gemini/OpenCode 的 Swift 编译兼容性，并包含最新 Grok 卸载与目录偏好修复。

**兼容性：** Nori 仍处于早期开发阶段，支持 macOS 13+。macOS 13–26 使用分隔条布局技巧收纳；macOS 27 为私有系统接口实验模式，按整个应用隐藏图标，系统更新可能使其失效。原菜单在 macOS 原有位置打开。macOS 13–26 和 Intel 的行为尚未在独立实机上验证。

Apple 芯片下载 `Nori-arm64.dmg`，Intel 下载 `Nori-x86_64.dmg`。保持现有 App 签名身份和 Sparkle 更新公钥。使用项目固定自签名证书，未经 Apple 公证。

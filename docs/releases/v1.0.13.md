# Nori 1.0.13

- Make cleanup categories and file rows selectable across their full width. Keep expansion and file actions separate so one click performs one action; show protected items as read-only and retain checkbox accessibility.
- Apply the same row selection behavior to Agent cleanup and uninstall data drawers, with clear partial-selection states and consistent selected surfaces.
- Improve Agent checkbox responsiveness by caching path overlap relationships and deferring deletion metadata snapshots until cleanup starts. Refresh the cache when inventory changes and reconcile selections against current paths.
- Include the Nori product video source project and reusable assets in the repository.

Download `Nori-arm64.dmg` for Apple silicon or `Nori-x86_64.dmg` for Intel. Supports macOS 13+. This release retains the fixed self-signed App certificate and Sparkle update key and is not Apple-notarized. Cross-version permission retention on another Mac remains unverified.

# Nori 1.0.13 · 中文

- 清理分类和文件行支持整行勾选，展开及文件操作保持独立，避免一次点击触发多个动作；受保护条目只读，并保留复选框无障碍语义。
- Agent 清理和卸载数据列表采用一致的整行选择方式，明确展示部分选择状态及选中面板。
- 缓存路径重叠关系，改善 Agent 勾选响应速度；删除元数据仅在执行清理时创建快照。扫描更新后重建缓存，并按当前路径校正选择。
- 仓库加入 Nori 产品宣传视频源码工程及可复用素材。

Apple 芯片下载 `Nori-arm64.dmg`，Intel 下载 `Nori-x86_64.dmg`。支持 macOS 13+。本版保持固定 App 自签名证书和 Sparkle 更新公钥，未经 Apple 公证；另一台 Mac 上的跨版本权限保留尚未验证。

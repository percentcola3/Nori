# Nori 1.0.7

**Early development: Nori is not yet stable.** Review cleanup selections and keep backups of important data. macOS 13+ remains supported.

- Let independent pages scan, check updates and manage selections while another page is working. Each page still prevents duplicate operations, and tasks that share application data or package-manager state keep their mutation guards.
- Check Nori updates during ongoing work, while deferring installation restart until the app is safe to relaunch. Keep other Software-page update requests bound to their own activity and the selected installation.
- Show administrator cleanup consent before expensive freshness review, reuse the scan's permission evidence and request system authorization before ordinary cleanup routes. Revalidate the confirmed identities and paths before deletion; declined authorization does not prevent eligible ordinary cleanup.
- Carry explicitly selected uninstalled Agent residuals through validation and retry. Preserve the selected paths without silently dropping them or expanding the cleanup scope.
- Keep uninstall progress on the Software page, and avoid replacing an existing confirmation with a late asynchronous result.
- Preserve the existing App signing identity and Sparkle update public key.

Download `Nori-arm64.dmg` for Apple silicon or `Nori-x86_64.dmg` for Intel. Existing Sparkle-enabled releases can detect this update. The self-signed App is not Apple-notarized; cross-version privacy permission retention on another Mac has not yet been verified.

# Nori 1.0.7 · 中文

**早期开发阶段，目前尚不够稳定。** 清理前请核对所选内容，并保留重要数据备份。继续支持 macOS 13+。

- 其他页面工作时，独立页面仍可扫描、检测更新和勾选内容。每页继续阻止重复操作；共享应用数据或包管理器状态的任务保留修改互斥。
- Nori 可在任务进行中检测自身更新，安装重启仍等待安全时机。软件页的其他更新请求继续受自身任务状态及所选安装范围约束。
- 管理员清理先提示确认，再进行较耗时的完整复核；复用扫描的权限证据，并在普通清理路线之前请求系统授权。删除前重新校验确认时的路径和身份；拒绝管理员授权后，符合条件的普通清理仍可执行。
- 用户明确勾选的已卸载 Agent 残留可继续进入校验和重试，保留原有选择，不静默丢弃或扩大清理范围。
- 软件卸载进度保留在软件页，异步结果不会覆盖已经打开的确认窗口。
- 保持现有 App 固定签名身份和 Sparkle 更新公钥。

Apple 芯片下载 `Nori-arm64.dmg`，Intel 下载 `Nori-x86_64.dmg`。已有支持 Sparkle 的版本可通过 App 更新检查检测本版。App 使用自签名，未经 Apple 公证；尚未在另一台 Mac 验证跨版本隐私授权保留。

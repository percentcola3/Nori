# Nori 1.0.8

**Early development: Nori is not yet stable.** Review cleanup selections and keep backups of important data. macOS 13+ remains supported.

- Manage Git repositories from the directory browser: inspect the current branch and repository status, switch local branches, and pull upstream changes using fast-forward updates.
- Guard Git operations against uncommitted changes, in-progress repository operations, branches occupied by other worktrees, and overwriting ignored local files. Bound command output and execution time, and refresh directory sizes and search results after changes.
- Reduce directory cache memory by retaining detailed size trees only for visible roots within smaller node budgets. Pause background size observation after leaving the directory page and release detailed trees while keeping cached summaries available.
- Preserve the existing App signing identity and Sparkle update public key.

Download `Nori-arm64.dmg` for Apple silicon or `Nori-x86_64.dmg` for Intel. Existing Sparkle-enabled releases can detect this update. The self-signed App is not Apple-notarized; cross-version privacy permission retention on another Mac has not yet been verified.

# Nori 1.0.8 · 中文

**早期开发阶段，目前尚不够稳定。** 清理前请核对所选内容，并保留重要数据备份。继续支持 macOS 13+。

- 目录浏览器新增 Git 仓库管理：查看当前分支和仓库状态、切换本地分支，并以快进方式拉取上游更新。
- Git 操作检查未提交更改、进行中的仓库操作及被其他工作树占用的分支，避免覆盖被忽略的本地文件。限制命令输出和执行时间，操作后刷新目录容量及搜索结果。
- 降低目录缓存内存占用：仅在较小节点预算内保留可见目录的详细容量树。离开目录页后暂停后台容量监测，释放详细树，同时保留缓存汇总值。
- 保持既有 App 签名身份与 Sparkle 更新公钥不变。

Apple 芯片下载 `Nori-arm64.dmg`，Intel 下载 `Nori-x86_64.dmg`。已支持 Sparkle 的版本可检测本次更新。应用使用固定自签名证书，未经 Apple 公证；另一台 Mac 上的跨版本隐私授权保留尚未验证。

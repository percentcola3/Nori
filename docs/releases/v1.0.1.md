# Nori 1.0.1

Nori supports **macOS 13 Ventura and later**. Native Liquid Glass is available on macOS 26 and later, with compatible materials on earlier systems.

- **Check for updates in Nori.** Sparkle adds manual and automatic update checks in Settings. Downloaded updates are verified using a fixed Ed25519 public key; installing an update remains your choice. Version 1.0.0 needs one manual installation of 1.0.1 to gain this feature.
- **Choose frames during capture.** Fixed-ratio capture offers iPhone and iPad frames, including the iPad 3:4 ratio. The editor keeps your capture frame while you change background presets; its Mac-style preset remains available. Older device-preset preferences migrate to a visible preset.
- **Keep signing identity stable.** This release reuses the exact App certificate, bundle identifier, and designated requirement from 1.0.0. The development installer also blocks accidental changes to an existing stable signature.
- **Clarify system compatibility.** The English and Chinese READMEs now state macOS 13+ in the introduction and explain the Liquid Glass requirement separately.

Download `Nori-arm64.dmg` for Apple silicon or `Nori-x86_64.dmg` for Intel. Quit Nori, open the DMG, and replace Nori.app in `/Applications`. Both packages include the same fixed App signing identity as 1.0.0.

The App is **self-signed and not Apple-notarized**. On first installation, macOS may require **System Settings → Privacy & Security → Open Anyway**. Migration from a local/development signature may require permission renewal; privacy-grant retention depends on macOS.

The release includes architecture-specific signed update feeds, `RELEASE-IDENTITY.txt`, and `SHA256SUMS`. Keep the downloads together and verify them with:

```sh
shasum -a 256 -c SHA256SUMS
```

# Nori 1.0.1 · 中文

Nori 支持 **macOS 13 Ventura 及以上**。macOS 26 及以上使用原生液态玻璃，较早系统使用兼容材质。

- **在 App 内检查更新。** 设置页新增 Sparkle 手动和自动更新检查。下载的更新由固定 Ed25519 公钥验证，安装由你决定。1.0.0 用户需要手动安装一次 1.0.1，才能获得此功能。
- **在截取时选择设备外框。** 按比例截取支持 iPhone 和 iPad 外框，增加 iPad 3:4 比例。编辑器切换背景预设时保留截取选择的相框，Mac 窗口样式预设仍可使用；旧的设备预设偏好会迁移到可见预设。
- **保持固定签名。** 复用 1.0.0 的 App 证书、Bundle ID 和完整签名要求。开发安装脚本也会阻止已有稳定签名被意外切换。
- **明确系统兼容性。** 中英文 README 首段明确说明 macOS 13+ 支持，并单独解释液态玻璃的版本要求。

Apple 芯片下载 `Nori-arm64.dmg`，Intel 下载 `Nori-x86_64.dmg`。退出 Nori 后打开 DMG，将 Nori.app 覆盖安装到 `/Applications`。两个安装包均保持与 1.0.0 相同的固定 App 签名身份。

本版使用**自签名，未经 Apple 公证**。首次安装可能需要在“系统设置 → 隐私与安全性”中选择“仍要打开”。从本地或开发签名迁移可能需要重新授权；隐私权限保留受 macOS 行为影响。

附件包含两个架构的签名更新源、`RELEASE-IDENTITY.txt` 和 `SHA256SUMS`。将下载文件放在同一目录，执行 `shasum -a 256 -c SHA256SUMS` 校验。

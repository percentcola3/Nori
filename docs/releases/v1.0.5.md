# Nori 1.0.5

**Early development: Nori is not yet stable.** Review cleanup selections and keep backups of important data. macOS 13+ remains supported.

- Check installed application and CLI versions from the Software page. Supported sources include Homebrew, npm/pnpm, pipx/uv, Cargo, Sparkle feeds and the Mac App Store; unavailable or unsupported checks remain distinct from an up-to-date result.
- Show an update action only when a newer version is found. Supported package-manager installations can update in place; other supported applications open their original updater, official download page or App Store. If the target is running, confirm closing its processes before updating. Verify the installed version after automatic updates.
- Confirm application uninstall before proceeding, with an enhanced warning for running applications and helpers. After confirmation, stop the scoped processes, remove the application first, then clean the selected residual data. Preserve the selected data scope in queued requests, simplify completed uninstall feedback and improve localized failure explanations.
- Keep discovered CLI installations visible when version probes or size measurements exceed their budget. Discover ordinary packages across multiple Homebrew Cellars, Node prefixes, pipx/uv environments, Cargo roots and Go paths. Deduplicate physical aliases while retaining separate installations of the same package, and bind update/uninstall commands to the selected installation root.
- Surface supported Python, Rust, Java and Shell tools alongside package-manager installations. Externally managed runtimes remain read-only rather than receiving a guessed uninstall command.
- Preserve the existing App signing identity and Sparkle update public key.

Download `Nori-arm64.dmg` for Apple silicon or `Nori-x86_64.dmg` for Intel. Existing Sparkle-enabled releases can detect this update. The self-signed App is not Apple-notarized; cross-version privacy permission retention on another Mac has not yet been verified.

# Nori 1.0.5 · 中文

**早期开发阶段，目前尚不够稳定。** 清理前请核对所选内容，并保留重要数据备份。继续支持 macOS 13+。

- 软件页新增应用与 CLI 版本检测，支持 Homebrew、npm/pnpm、pipx/uv、Cargo、Sparkle 更新源和 Mac App Store 等来源；检测失败或暂不支持时，不会误报为已是最新版。
- 仅检测到新版时显示更新操作。支持的包管理器安装可直接更新；其他支持的应用转到原程序更新器、官方下载页或 App Store。目标正在运行时，先确认是否关闭相关进程；自动更新完成后复核安装版本。
- 卸载应用前先确认，应用或辅助进程仍在运行时加强提示。确认后停止属于该应用的进程，先移除应用本体，再清理用户选择的残留数据。排队请求保留确认时的数据范围，简化卸载完成后的展示，并完善失败原因的本地化说明。
- 修复通用 CLI 漏检：版本探测和容量统计超时不再丢弃已发现的工具。收集多个 Homebrew 安装目录、Node 全局安装前缀、pipx/uv 环境、Cargo 根目录和 Go 路径中的普通工具；合并同一物理安装的路径别名，保留不同目录的同名安装，并将更新、卸载命令绑定到所选安装目录。
- 展示已支持的 Python、Rust、Java 和 Shell 工具。外部管理的运行时保留只读边界，不猜测卸载命令。
- 保持原来的 App 固定签名身份和 Sparkle 更新公钥。

Apple 芯片下载 `Nori-arm64.dmg`，Intel 下载 `Nori-x86_64.dmg`。已有支持 Sparkle 的版本可通过 App 更新检查检测本版。App 使用自签名，未经 Apple 公证；尚未在另一台 Mac 验证跨版本隐私授权保留。

# Nori 1.0.17

- Add an explicit whole-app-data review after application, command-line tool and Agent removal. Uninstalled application and Agent leftovers appear as unselected review items; deletion rechecks ownership and file identity and moves approved data to Trash while protecting shared data, installed owners and changed files.
- Add directory sorting and improve folder size and file listing updates.
- Keep cleanup and other mutations blocked while uninstall data is being reviewed. Update regression fixtures to distinguish installed-app cache cleanup from uninstalled-owner data review.
- Parallelize release validation and architecture builds, reusing verified signed builds during assembly while requiring every regression group to pass.

Download `Nori-arm64.dmg` for Apple silicon or `Nori-x86_64.dmg` for Intel. Supports macOS 13+. Retains the existing self-signed App certificate and Sparkle update key; not Apple-notarized. Cross-version permission retention on another Mac remains unverified.

# Nori 1.0.17 · 中文

- 应用、命令行工具与 Agent 卸载后可明确选择复核完整应用数据。已卸载应用与 Agent 的残留以默认不勾选的复核项展示；执行时重新核对归属和文件身份，经确认的数据移入废纸篓，继续保护共享数据、仍在安装的所有者及发生变化的文件。
- 增加目录排序，改善文件夹容量和文件列表更新。
- 卸载数据复核期间阻止清理与其他修改操作；更新回归夹具，区分已安装应用的缓存清理和已卸载所有者的数据复核。
- 发布验证与双架构构建并行执行，组装时复用已验证的签名构建，并要求全部回归分组通过。

Apple 芯片下载 `Nori-arm64.dmg`，Intel 下载 `Nori-x86_64.dmg`。支持 macOS 13+。保持原有 App 自签名证书和 Sparkle 更新公钥，未经 Apple 公证；另一台 Mac 上的跨版本权限保留尚未验证。

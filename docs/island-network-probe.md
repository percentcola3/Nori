# 灵动岛网络检测

点击顶部或侧边灵动岛的「网络」指标，在现有岛面板内打开网络检测详情。原有上下行实时流量和走势图保持显示。

- Ping：目标可填写域名、IPv4 或 IPv6；发送四个探测包，显示平均延迟和丢包率。ICMP 不响应会显示丢包，不能据此单独断定互联网不可用。
- 带宽测速：使用 macOS 自带 `/usr/bin/networkQuality -c`，显示实际下载、上传 Mbps 和可获得的空载延迟。数值由工具的 bit/s 转换，区别于主指标的实时 KB/s／MB/s。
- 测试只在点击按钮时启动，一次只运行一个测试。Ping 最长十秒，带宽测试最长四十五秒；支持停止。关闭详情、隐藏灵动岛、打开主窗口或退出 Nori 时停止当前检测。
- 网络面板在点击后保持打开，便于输入目标及查看结果；关闭按钮恢复普通指标展示。
- 使用独立 MoleEngine，参数直接传给系统工具；不使用 shell 拼接，也不停止清理或开发工具的命令。输出限制 64 KiB，迟到结果不覆盖取消后的状态。
- 带宽测速会主动产生上下行流量；测试端点和协议由系统 networkQuality 决定，无额外安装依赖。

验证：`script/test_island_network_probe.sh` 覆盖目标校验、延迟／丢包解析、带宽单位和错误输出、真实回环 Ping、取消及命令隔离；`script/test_island_side_presentation.sh` 覆盖两种语言、顶部／左右侧栏的真实详情视图与命中区域。布局截图使用合成测量值，不是本机网速结果。

本地日志：`dist/island-network-validation/`。实际网络速度由所在网络、代理／VPN、测试服务器和流量负载决定。

安装后的实际界面核对：点击网络指标打开岛内面板，回环 Ping 显示约 0.1 ms／0% 丢包；系统带宽测试返回下载约 228.8 Mbps、上传约 70.3 Mbps、空载延迟约 406 ms。另一次测速启动后停止，界面恢复可操作并显示「已停止」。这些是本机当时的测量，不是固定示例值或线路保证速度。按钮的无障碍名称固定，实时流量通过无障碍数值更新。

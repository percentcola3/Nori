# 影片方向 · Nori 产品介绍片

范围（用户确认）：产品全貌，macOS 桌面端（菜单栏 + 主窗口 + 灵动岛）；风格 `repo`；横版 1920×1080 / 30fps，57.6 秒；中文为主、标题中英双语。Nori 是原生 SwiftUI，界面按源码尺寸与 Theme token 在 HTML 中忠实重建（用户已授权），吉祥物直接加载仓库里的原版动画 SVG。

## 2. 产品气质

- **做什么、给谁、什么感觉**：给 macOS 13+ 用户，尤其是开发者和重度 AI Agent 用户的「安静照看 Mac 的小伙伴」（`docs/brand/nori-design.md`）。腾磁盘空间、识别开发缓存与 Agent 数据、监控系统、处理日常小事。感觉是**安静、克制、可信、带一点可爱**，不是“一键加速 1000%”式的清理软件。
- **设计语言**：墨蓝 `#10283F` + 冰蓝 `#BFEAF2`（`SimpleMole/Views/Theme.swift` `EarthBluePalette`）；单层液态玻璃，着色 `#10283F` α0.66；表面 `white 6/10/16%`，分隔线 `white 13%`；状态色 success `#53C68C`、warning `#E3A43C`、danger `#E56672`；行圆角 9pt、胶囊导航 36pt 高；正文 11–12pt SF Pro / 苹方，数字等宽。暗色主题是主力外观。
- **母题候选**：
  - 吉祥物 Nori：倾斜的圆润果冻形体、两颗胶囊眼睛（`Support/Nori/design.json`）。
  - 「工作中」的三色缎带环绕：水蓝 `#69C7DD`、柔金 `#F2C66D`、淡紫 `#B8A7DF`（`nori-working.svg`）。
  - 成功：右下角绿色 ✓ 圆标 + 彩纸（`nori-success.svg`）。
  - 灵动岛：从屏幕刘海长出来的面板（`FloatingIslandView.swift`，虚拟刘海宽 193、面板宽 468）。
  - 数据形态：一行行带大小的类别、Safe / Warning 标签、可回收字节数。

## 4. 选择与理由

选 **A 静潮**。Nori 的品牌是“安静、更干净”，吉祥物和三色缎带是它最独特的识别；从容的节奏更适合需要信任的清理工具，比 C 的冲击感更贴切。B 的刘海一镜辨识度高，但 Agent 清理、开发者工具这些主卖点不长在刘海上，所以只借它做灵动岛那一镜。

**本片专属手法**：

1. **因为 Nori 工作时有三色缎带环绕，所以章节转场用这三条缎带横扫全屏擦除**：水蓝、柔金、淡紫依次扫过，后一个镜头在缎带后面露出来。只用在大段落之间（共 3 次）。
2. **因为界面是单层液态玻璃，所以背景是缓慢漂移、模糊的三色光团**：玻璃面板的 `backdrop-filter` 有东西可以折射，画面才看得出“玻璃”。功能镜头里光团压暗，不抢界面。
3. **因为吉祥物有真实的工作 / 成功动画，所以关键反馈直接播放仓库里的原版 SVG**：扫描时 `nori-working`，清理完成时 `nori-success`（✓ + 彩纸），按影片时间逐帧设定 CSS 动画进度。
4. **因为灵动岛长在刘海里，所以这一镜从屏幕顶端的刘海开始，面板从刘海形状向下长出来**，指标数字随后滚动。
5. **因为 Nori 的卖点是“分得清”（Safe 可重建 / Warning 是历史），所以 Agent 镜头里勾选是逐个落下的**：Safe 项被勾上，会话历史留空，并用暖色描边提示“需要你确认”。

**与本工作区既往影片的区别**：这是本工作区第一支片子，没有可对照的前作。

## 5. 画面规范

- **画幅**：1920×1080，30fps，底色 `#0A1826`（比品牌墨蓝深一档，留给光团和玻璃发亮）。安全区：左右 120px，底部 140px 内不放文字。
- **字号阶梯**：
  - 英文主标题 SF Pro Display（`-apple-system`）64px / 600，字距 −1px；中文主标题苹方 SC 56px / 600。英文在上、冰蓝 `#BFEAF2`；中文在下、白色。
  - 说明：苹方 28px / 400，`rgba(255,255,255,.72)`，行高 1.5，最多两行，列宽 560px。
  - 章节小标：SF Pro 20px / 600，字距 0.18em，大写，水蓝 `#69C7DD`。
  - 品牌字标 “Nori”：SF Pro Rounded 160px / 700。
- **界面上镜倍数**：产品正文 12pt → 2× 放大，正文在画面上 24px。只做局部特写（列表区、开发者面板、刘海区），不放整窗。功能镜头界面占右侧约 1040px，标题列在左侧 x=140–700。
- **明暗主题**：全片用产品暗色主题。
- **动效语法**：入场用 `expo.out` / `power3.out`，0.5–0.9s；镜头推拉 `sine.inOut`，缓慢持续；文字只有标题用逐字模糊入场，说明用整行上浮，界面行逐行滑入。**不用**：回弹（吉祥物自带的果冻感除外）、彩虹渐变、旋转飞入、长交叉淡化。
